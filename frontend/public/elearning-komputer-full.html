Modul Pembelajaran

01

Computer System Setup

Objektif: Pelajar dapat mengenal pasti komponen komputer, menerangkan fungsinya dan melakukan konfigurasi asas sebelum komputer digunakan.

Nota pembelajaran

  • Sistem komputer ialah gabungan perkakasan, perisian dan pengguna untuk menerima input, memproses data, menyimpan maklumat dan menghasilkan output.
  • Perkakasan ialah komponen fizikal seperti CPU, motherboard, RAM, storage, monitor, keyboard dan mouse.
  • CPU memproses arahan dan data, motherboard menghubungkan komponen utama, RAM menyimpan data sementara, manakala HDD/SSD menyimpan data kekal.
  • BIOS/UEFI berjalan sebelum sistem operasi untuk tetapan awal, masa/tarikh, boot priority dan konfigurasi hardware.
  • Driver membolehkan sistem operasi berkomunikasi dengan hardware seperti Wi-Fi, audio, printer dan graphic card.

Kuiz ringkas

  1. Apakah fungsi CPU? A. Menyimpan data B. Memproses arahan C. Mengeluarkan bunyi D. Menyambungkan internet
  2. Apakah fungsi RAM? A. Simpan data kekal B. Bekalkan elektrik C. Memori sementara D. Paparkan grafik
  3. Driver digunakan untuk apa? A. Menghubungkan hardware dengan sistem operasi B. Menambah RAM C. Memadam virus D. Membuka browser

Tugasan / Amali

Kenal pasti sekurang-kurangnya lapan komponen komputer, terangkan fungsi setiap komponen, ambil gambar/screenshot, nyatakan spesifikasi komputer dan susun laporan PDF.

02

Computer System Maintenance

Objektif: Pelajar dapat melakukan penyelenggaraan hardware dan software untuk memastikan komputer stabil, bersih dan selamat digunakan.

Nota pembelajaran

  • Penyelenggaraan membantu mengurangkan overheating, virus, storage penuh, sistem perlahan dan kerosakan komponen.
  • Preventive maintenance dibuat sebelum masalah berlaku, corrective maintenance dibuat selepas kerosakan, predictive maintenance melihat tanda awal seperti suhu tinggi atau bunyi abnormal.
  • Bersihkan fan, heatsink, casing dan motherboard dengan peralatan sesuai serta semak kabel power, SATA, USB dan monitor.
  • Kemas kini sistem operasi, driver dan aplikasi; semak startup application dan gunakan Disk Cleanup atau Storage Sense.
  • Backup data ke external drive, Google Drive, OneDrive, NAS atau server organisasi.

Kuiz ringkas

  1. Apakah tujuan preventive maintenance? A. Tunggu rosak B. Mencegah masalah C. Beli komputer baru D. Padam OS
  2. Apakah yang boleh menyebabkan overheating? A. RAM besar B. Fan penuh habuk C. Keyboard baru D. Internet laju
  3. Disk Cleanup digunakan untuk apa? A. Membersihkan fail sementara B. Menambah RAM C. Menguatkan Wi-Fi D. Membuka server

Tugasan / Amali

Sediakan checklist maintenance: semak storage, update OS/aplikasi, antivirus scan, backup satu folder dan lampirkan screenshot sebelum/selepas.

03

Computer System Repair

Objektif: Pelajar dapat menggunakan langkah troubleshooting sistematik untuk mencari punca dan menyelesaikan masalah asas komputer.

Nota pembelajaran

  • Troubleshooting ialah proses mengenal pasti, menganalisis dan menyelesaikan masalah komputer atau rangkaian.
  • Aliran kerja: kenal pasti masalah, semak punca, buat ujian, baiki dan sahkan sistem berfungsi semula.
  • Masalah biasa termasuk tiada paparan, komputer perlahan, blue screen, gagal boot, storage tidak dikesan dan Wi-Fi bermasalah.
  • Gunakan Task Manager, Device Manager, Disk Management, Command Prompt, Event Viewer dan Windows Memory Diagnostic.

Kuiz ringkas

  1. Jika komputer hidup tetapi tiada paparan, apa yang boleh diperiksa dahulu? A. Printer B. Kabel monitor dan RAM C. Browser D. Speaker
  2. Tool untuk melihat aplikasi guna banyak RAM? A. Task Manager B. Paint C. Notepad D. Calculator
  3. Apakah maksud troubleshooting? A. Install game B. Mencari dan menyelesaikan masalah C. Backup data D. Cetak dokumen

Tugasan / Amali

Pilih satu masalah komputer, nyatakan simptom, kemungkinan punca, langkah troubleshooting, penyelesaian akhir dan bukti screenshot/gambar.

04

Server Installation

Objektif: Pelajar dapat menerangkan fungsi server dan memasang server asas dalam virtual machine dengan konfigurasi rangkaian yang betul.

Nota pembelajaran

  • Server menyediakan perkhidmatan kepada komputer client dalam rangkaian seperti file server, web server, DNS, DHCP, database dan authentication.
  • Sistem operasi server termasuk Ubuntu Server, Windows Server, Debian Server dan Rocky Linux.
  • Server memerlukan processor stabil, RAM mencukupi, storage besar, network connection baik dan backup konsisten.
  • IP statik penting supaya alamat server kekal dan mudah dicapai oleh client.
  • Virtual machine seperti VirtualBox, VMware Workstation dan Proxmox membolehkan latihan server tanpa hardware server sebenar.

  2. Contoh server untuk menyimpan fail pengguna? A. File Server B. Game Server C. GPU Server D. Printer Driver
  3. Software virtual machine? A. VirtualBox B. Microsoft Word C. Canva D. Chrome

Tugasan / Amali

Install Ubuntu Server dalam VirtualBox, tetapkan nama server, username/password admin, static IP dan lampirkan screenshot pemasangan serta semakan IP.

05

Network Connectivity Setup

Objektif: Pelajar dapat mengkonfigurasi sambungan rangkaian asas dan melakukan ujian menggunakan ipconfig, ping dan nslookup.

Nota pembelajaran

  • Rangkaian komputer membolehkan peranti berkongsi data, internet, printer dan perkhidmatan server.
  • Router menghubungkan rangkaian ke internet, switch menghubungkan peranti dalam LAN, access point memberi Wi-Fi dan firewall mengawal trafik.
  • IP address mengenal pasti peranti, subnet mask menentukan julat rangkaian, gateway ialah laluan keluar dan DNS menukar domain kepada IP.
  • Command asas: ipconfig untuk konfigurasi IP, ping untuk ujian capaian dan nslookup untuk semakan DNS.

  2. Apakah fungsi DNS? A. Tambah RAM B. Tukar nama domain kepada IP C. Hapus virus D. Tambah storage
  3. Command untuk menguji sambungan network? A. ping B. copy C. delete D. shutdown

Tugasan / Amali

Tetapkan IP statik, subnet mask, gateway dan DNS; jalankan ipconfig, ping gateway, ping google.com dan nslookup google.com lalu laporkan hasil.

06

Security Setup

Objektif: Pelajar dapat menerangkan ancaman asas dan melaksanakan tetapan keselamatan penting pada komputer serta akaun pengguna.

Nota pembelajaran

  • Keselamatan sistem melindungi komputer, rangkaian, akaun dan data daripada ancaman, kerosakan atau akses tanpa kebenaran.
  • Ancaman biasa termasuk virus, malware, ransomware, phishing dan unauthorized access.
  • Password selamat sebaiknya minimum 12 aksara, unik dan menggabungkan huruf besar, huruf kecil, nombor serta simbol.
  • Firewall mengawal trafik masuk/keluar, antivirus mengesan malware, backup membantu pemulihan dan MFA menambah lapisan keselamatan.

Kuiz ringkas

  2. Apakah phishing? A. Memancing ikan B. Penipuan mencuri maklumat C. Bersihkan komputer D. Jenis storage
  3. Apakah MFA? A. Multi-Factor Authentication B. Main File Access C. Memory Format Application D. Manual Firewall Access

Tugasan / Amali

Semak antivirus, firewall, password latihan, backup satu folder penting, aplikasi/extension tidak dikenali dan sediakan laporan keselamatan dengan screenshot.
